# Design evaluation standardization

The evaluation bridge connected optimized execution to frozen data and explicit metric definitions. Candidate keys, occurrence maps, source fingerprints, and item-level acceptance made it possible to reconstruct each reported population.

The full pLDDT cache held 4,862 unique eligible sequences plus one empty-response NaN sentinel. The native coverage audit failed. A documented in-memory normalization removed only that identified placeholder before checking all 8,692 eligible candidate slots. The native failure remained visible in the accepted record.

A subsequent fixed-seed retest exposed a denominator issue. Eligible candidates reproduced their historical Repeat values, while the old summary also included over-length candidates. ProTrek's InterPro-text convention was distinguished from a separate problem-text convention. ProTrek and full-database sequence Novelty reproduced their same-convention historical values exactly.

Legacy Easy novelty values outside the expected interval were retained and counted. Hard novelty remained the primary result. The subset retest supports the stated scoring path and scope; new inputs still require their own provenance and acceptance.
