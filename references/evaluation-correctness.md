# 评测正确性与完整性

冻结原始数据、预测、解析规则、评分版本和参考库身份。生成 checkpoint 与评分工具模型分别记录。明确指标单位、有效性、总槽位、候选键、空值和长度处理，再开始比较新旧结果。

按主键核对所有预期槽位，拒绝重复、缺失、错题与错列。去重只改变计算次数，回填与汇总恢复出现次数。有效率的分母包括无效槽位，其他指标依据已约定的 eligible 集合汇总。保留不同文本口径、长度筛选和旧汇总的身份。

阶段退出码、输入输出哈希、代码与配置来源、逐项结果覆盖和主指标复算共同支持验收。阶段报告的 `passed` 需结合其范围解释。单波通过、保护生效、最终状态核对通过分别保留自己的结论，完整任务取决于全部必需阶段。

出现 NaN、哨兵或越界时保留原值和原生失败记录。只对有明确身份且符合约定语义的占位项做带记录的归一化，再验证有效项。旧实现异常如果属于复现范围，单列异常计数和主比较字段，任何公式修订都建立新版本结果。

按候选、seed、批次和全量规模分别声明结果。按实际调用链理解新旧差异，已完成的子集复测可验证评分实现，新的模型或全量产物仍需要各自的来源和覆盖验收。例子见 [标准 Design](../cases/design-standardization/README.md)。
