# GPU 性能诊断与改进

先按冷启动、权重载入、主机到设备传输、预热或编译、稳态前向、结果写出分别计时。保留硬件、驱动、框架、精度、batch 与张量形状，以及是否复用了权重副本。同期记录 CPU、I/O 和内存压力，多卡一起启动可能放大主机侧成本。

用真实模型 trace 选择主要成本，再做相同形状和精度的算子实验。GPU 同步计时应包含预热说明，profiler 开销与正常运行计时分别记录。原实现是否调用融合算子要从实际调用或 trace 确认，迁移后的性能由硬件与具体算子路径共同决定。

分桶、batch budget 和分片成本使用模型实际长度与 padding 语义。先去重计算再按原槽位还原。多 worker 独立输出，检查每个 worker 的结果与映射。遇到设备可见性或 kernel 指针问题，先在单设备进程验证运行时条件。

优化决策同时看算子时间、完整模型时间、数值分布和异常。算子加速后重测端到端关键路径，保留无收益或退化的方案。按用户约定的容差报告均值、最大差、分位数、离群点与 NaN。需要回退时记录选择条件与额外耗时。

案例参数与负例见 [pLDDT / C550](../cases/plddt-c550/README.md)。
